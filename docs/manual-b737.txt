JAL/JTA BOEING 737-700 FLIGHT CREW OPERATING MANUAL (FCOM) & SOP 本マニュアルは、日本航空（JAL）および日本トランスオーシャン航空（JTA）におけるBoeing 737-700型機の標準運航手順（SOP）を規定する。
PF（Pilot Flying）およびPM（Pilot Monitoring）は、本規程に定めるコールアウト、指差し呼称、および操作手順を厳格に遵守すること。
曖昧な操作や推測に基づくシステム介入は重大なインシデントに直結する。

PF/PM入室後、PMは以下の順序でオーバーヘッドパネルを確実にセットし、システムを構築する。
 1. IRS Mode Selectors: NAV にセットし、アライメントを開始する。
 2. Fuel Pumps: 搭載燃料に応じ、必要なポンプを ON。
 3. Window Heat: 全てのスイッチを ON。
 4. Electric Hydraulic Pumps (A/B): ON。
システム圧力が上昇したことを確認する。
 5. APU Bleed: ON。
 ⚠

【DUAL BLEED CAUTION】: APU BleedがONの状態で、Engine Bleed Valveが開いている場合、「DUAL BLEED」ライトが点灯する。
この状態でエンジン推力をアイドル以上に増加させると、APUへの逆流が生じ致命的な損傷を招く。
必ずアイドル推力を厳守すること。
 2.2 FMC / CDU セットアップフロー (PF/PM) FMCへのデータ入力は「IDENT」ページから順次実行する。
 1. IDENT: 機種（737-700）およびエンジンレーティング、Nav Dataの有効期限を確認。
 2. POS INIT: 現在位置を入力し、IRSアライメントを完了させる。
 3. ROUTE: 出発地、目的地、SID/STAR、およびエンルートのウェイポイントを入力・実行(EXEC)する。
 4. PERF INIT: ZFW、FUEL、Reserve燃料を入力し、Cruise Altitudeをセットする。
 5. N1 LIMIT: OAT（外気温度）を入力し、必要なDerate（減推力）を選択する。
 6. TAKEOFF REF: Flaps設定を入力し、V1, VR, V2を算出・確認する。
CGを入力し、Trim値を決定する。
 2.3 MCP (Mode Control Panel) 初期設定手順 ● F/D (Flight Director): PF側を先にONにし、続いてPM側をONにする（Master表示がPF側になることを確認）。
 ● COURSE: 出発滑走路の磁方位（Inbound Course）をPF/PM両側にセットする。
 ● IAS/MACH: FMCで算出された V2速度 をセットする。
 ● HEADING: 出発滑走路の磁方位（Runway Heading）をセットする。
 ● ALTITUDE: 管制承認された初期上昇高度（Initial Climb Altitude）をセットする。

 4.3 減速・降下手順 (10,000ft未満の速度管理) B737-700は空力性能が高く、降下中の減速が極めて困難である。
 1. スピードブレーキの段階的使用: 降下角が深く速度が増加する場合、PFはスピードブレーキレバーを「FLIGHT DETENT」まで展開する。
ただし機体振動（Buffet）が生じるため、必要最小限にとどめること。
 2. アーリー・デセラレーション (早期減速): 10,000ft通過時に250kts以下へ減速できないリスクがある場合、事前に水平飛行区間を設けるか、早めに Flaps 1 および Flaps 5 を展開し、フラップによる抗力で減速を図ること。

 1. Aviate / Navigate: PFはまず機体の姿勢と飛行経路の維持に全力を注ぐ。

 2. Memory Items: 第8章の暗記事項に該当する場合は直ちに実行する。
 3. QRH (Quick Reference Handbook): 機体が安定した後、PMがQRHを取り出し、PFの指示によりノンノーマル・チェックリストを開始する。
 ○ Identify: 故障箇所をEICAS/計器で相互確認。
 ○ Confirm: 不可逆的な操作（Engine Start Lever, Fire Switch, Generator等）を行う際は、必ず「Confirm Engine 1...」とPFに確認を求め、PFの「Confirmed」の返答を得てから実行する。
 IF環境下においては、システム異常が機体のコントロール喪失に直結する場合、無理なアプローチを継続せず、即座にゴーアラウンドし、安全な高度・空域で状況評価を行う「安全最優先」のJAL運航思想を貫徹すること。
